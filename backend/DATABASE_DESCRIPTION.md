# Описание базы данных проекта

База данных проекта `Movie Tracker Backend` предназначена для хранения учетных записей пользователей, их папок, списка фильмов и сериалов, а также социальных связей между пользователями. На текущий момент схема включает пять основных таблиц: `users`, `folders`, `watch_items`, `folder_saves` и `user_follows`.

Отдельно важно отметить, что других прикладных таблиц в текущей схеме проекта нет. Данные профиля пользователя хранятся прямо в таблице `users`, данные о библиотеке и истории просмотра находятся в таблице `watch_items`, пользовательские и системные папки хранятся в таблице `folders`, а социальные действия вынесены в таблицы `folder_saves` и `user_follows`. Отдельных таблиц `profiles`, `media`, `watch_history` или иных самостоятельных сущностей в текущей версии базы данных не предусмотрено.

Таблица `users` хранит учетные записи пользователей системы. Поле `id` является первичным ключом и уникальным идентификатором пользователя. Поле `email` содержит адрес электронной почты и должно быть уникальным. Поле `login` хранит уникальный логин пользователя, который используется для входа в систему и формирования ссылки на профиль. Поле `display_name` содержит отображаемое имя пользователя. Поле `extension_code` хранит уникальный код подключения браузерного расширения. Поле `avatar_key` используется для хранения выбранного предустановленного аватара, а поле `avatar_image` предназначено для хранения пользовательского изображения аватара. Поле `password_hash` содержит хэш пароля пользователя. Поле `created_at` хранит дату и время создания учетной записи.

Таблица `folders` хранит папки пользователя для организации медиаконтента. Поле `id` является первичным ключом таблицы. Поле `user_id` ссылается на таблицу `users` и показывает, какому пользователю принадлежит папка; при удалении пользователя его папки также удаляются. Поле `title` содержит название папки, а поле `description` хранит ее текстовое описание. Поле `access` определяет видимость папки, например приватный или публичный режим. Поле `is_system` показывает, является ли папка системной. Поле `system_key` хранит служебный ключ системной папки. Для одного пользователя значение `system_key` не может повторяться, что обеспечивается уникальным ограничением по полям `user_id` и `system_key`. Поля `created_at` и `updated_at` фиксируют время создания и последнего обновления папки. В проекте автоматически создаются системные папки с ключами `continue_watching`, `watched` и `will_watch`, которые соответствуют основным состояниям просмотра.

Таблица `watch_items` хранит фильмы и сериалы, добавленные пользователем в библиотеку или историю просмотра. Поле `id` является первичным ключом записи. Поле `user_id` ссылается на таблицу `users` и определяет владельца записи; при удалении пользователя связанные записи также удаляются. Поле `system_folder_id` ссылается на таблицу `folders` и указывает системную папку, которая соответствует текущему статусу просмотра; удалить такую папку, пока на нее ссылаются записи, нельзя. Поле `custom_folder_id` также ссылается на таблицу `folders`, но используется для дополнительного размещения записи в пользовательской папке и может быть пустым; если пользовательская папка удаляется, это поле автоматически становится пустым. Поле `source` показывает источник добавления записи и ограничено значениями `manual` или `extension`. Поле `content_type` определяет тип контента и принимает значения `movie` или `series`. Поле `title` хранит название фильма или сериала, а поле `source_url` содержит ссылку на исходную страницу контента. Поле `year` хранит год выпуска. Поле `genres` содержит список жанров в формате JSON. Поле `duration_text` хранит текстовое представление длительности, а поле `description` содержит описание контента. Поле `imdb_rating` предназначено для внешнего рейтинга, а поле `user_rating` хранит пользовательскую оценку в диапазоне от 1 до 10. Поле `comment` содержит заметку пользователя. Поле `status` хранит текущее состояние просмотра и ограничено значениями `planned`, `watching` или `completed`. Поле `progress_percent` показывает процент прогресса просмотра и ограничено диапазоном от 0 до 100. Поля `progress_seconds` и `duration_seconds` используются для хранения точного прогресса и длительности в секундах. Поля `season` и `episode` предназначены для сериалов. Поле `watched_at` хранит дату и время завершения просмотра. Поля `created_at` и `updated_at` фиксируют момент создания и последнего обновления записи.

Таблица `folder_saves` хранит информацию о сохранении публичных папок другими пользователями. Поле `id` является первичным ключом. Поле `viewer_user_id` ссылается на таблицу `users` и показывает, какой пользователь сохранил папку; при удалении пользователя эта связь удаляется автоматически. Поле `folder_id` ссылается на таблицу `folders` и указывает, какая именно папка была сохранена; при удалении папки соответствующие сохранения также удаляются. Поле `created_at` хранит дату и время создания такой связи. Для предотвращения повторного сохранения одной и той же папки одним и тем же пользователем используется уникальное ограничение по полям `viewer_user_id` и `folder_id`.

Таблица `user_follows` хранит связи подписки между пользователями. Поле `id` является первичным ключом записи. Поле `follower_user_id` ссылается на таблицу `users` и указывает пользователя, который подписался. Поле `followed_user_id` также ссылается на таблицу `users` и указывает пользователя, на которого оформлена подписка. Если один из этих пользователей удаляется, соответствующая запись о подписке удаляется автоматически. Поле `created_at` хранит дату и время создания подписки. Для того чтобы один пользователь не мог подписаться на одного и того же человека несколько раз, используется уникальное ограничение по полям `follower_user_id` и `followed_user_id`.

Связи между таблицами построены по принципу «один ко многим». Один пользователь может иметь много папок, много записей в `watch_items`, много сохраненных папок в `folder_saves`, а также много подписок и подписчиков через таблицу `user_follows`. Одна папка может содержать много записей о фильмах и сериалах и одновременно может быть сохранена многими пользователями. Таблица `watch_items` связывает пользователя с его медиаконтентом и одновременно соединяет этот контент с системными и пользовательскими папками.
