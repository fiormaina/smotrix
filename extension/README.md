# Smotrix: как установить и пользоваться

## Установка

1. Откройте `chrome://extensions`
2. Включите **Режим разработчика**
3. Нажмите **Загрузить распакованное расширение**
4. Выберите эту папку: `extension`

## Подключение

1. Откройте веб-платформу Movie Tracker
2. Войдите в аккаунт
3. Получите код привязки расширения
4. Нажмите на значок расширения "Смотрикс"
5. Введите код привязки
6. Нажмите **Подключить**

## Использование

1. Откройте поддерживаемый сайт с видео
2. Запустите фильм или серию
3. Смотрите как обычно

Расширение автоматически отправляет прогресс просмотра в аккаунт.

## Поддерживаемые сайты

- `amediateka.ru`
- `ivi.ru`
- `hd.kinopoisk.ru`
- `kion.ru`
- `premier.one`
- `viju.ru`
- `wink.ru`

## Если синхронизации нет

- проверьте, что расширение подключено к аккаунту
- обновите вкладку с плеером
- попробуйте поставить видео на паузу на несколько секунд
- убедитесь, что сайт входит в список поддерживаемых
